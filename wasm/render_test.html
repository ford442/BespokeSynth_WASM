Render Test Harness

Opens the main app with ?renderTest=1 to load a canonical module graph for visual regression. Prefer ?renderer=webgl for reliable PNG capture in CI/agents.

After the app loads, run in the browser console: await window.__bespoke.captureScreenshot() or await window.__bespoke.captureScreenshot({ x: 0, y: 40, width: 800, height: 500 })
